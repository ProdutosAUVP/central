# Catálogo do Design System — AUVP

Todos os componentes do Design System exportados **um a um**, nos temas **claro** e **escuro**, em **SVG** (vetor) e **PNG** (3× — alta resolução).

As imagens contêm **só o componente**, sobre o fundo do tema. Nada da interface do Design System em si — nem cabeçalho da página, nem barra lateral, nem o cartão de pré-visualização com o título e o botão de código.

**103 componentes** · 412 arquivos · gerado a partir de `/design-system`.

## Como a pasta está organizada

```
catalogo-design-system/
├── catalogo.json   # índice legível por máquina (nome, categoria, seção, âncora, dimensões)
├── claro/
│   ├── svg/<categoria>/<seção>/<componente>.svg
│   └── png/<categoria>/<seção>/<componente>.png
└── escuro/
    ├── svg/<categoria>/<seção>/<componente>.svg
    └── png/<categoria>/<seção>/<componente>.png
```

O caminho reproduz a navegação de `/design-system`: **categoria › seção › componente**. O nome do arquivo é o nome do componente no Design System, sem acento e em minúsculas — por isso variantes homônimas de componentes diferentes (`livro/default` e `checkbox/default`) não se confundem.

## Notas sobre os formatos

- **SVG** — vetor de verdade: cada caixa vira `<rect>`, cada texto vira `<text>` e as imagens entram embutidas em data URI. Escala sem perda e dá para inspecionar ou editar. As larguras de texto são fixadas com `textLength`, então o layout se mantém mesmo sem as fontes da marca instaladas; abrindo o arquivo no navegador, as fontes vêm do Google Fonts via `@import`. Cada arquivo traz `<title>` e `<desc>` com o nome e a descrição do componente.
- **PNG** — captura fiel do componente renderizado, em 3× (viewport de 1440px). É a referência pixel-perfect, inclusive de sombras, gradientes e desfoques.

## Como regerar

```bash
npm install --no-save playwright dom-to-svg
npm run build
node scripts/exportar-catalogo-design-system.mjs
```

O script abre `/design-system` num Chromium headless e captura tudo que estiver marcado com `data-ds-showcase` — ou seja, todo `<ComponentShowcase>` e todo `<SectionThemeToggle>`. Componente novo no Design System entra no catálogo sozinho, sem mexer no script.
